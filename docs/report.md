Чистка pdf
1) Из индекса pdf отчетов компании убрано оглавление, т.к. оно близко по смыслу к запросам но не несет информации

Отсеяно 3 страницы из 145, `TOP_K = 5`.

### Пример ответа на запрос: «Основные финансовые показатели эмитента»

Пример ответа до:
```
страницы в выдаче: 11, [2], [2], 16, 24   — два места из пяти занимает оглавление

Основные финансовые показатели эмитента представлены в следующих разделах:
*  1.4.1. Основные финансовые показатели, рассчитываемые на основе
   консолидированной финансовой отчетности эмитента [.., стр. 9]
*  1.4.2. Основные финансовые показатели, рассчитываемые на основе
   бухгалтерской (финансовой) отчетности эмитента [.., стр. 11]
```

Пример ответа после:
```
страницы в выдаче: 11, 16, 24, 3, 4

*  Консолидированная выручка Группы составила 289,5 млн евро,
   что на 14,1% больше по сравнению с 2024 годом [.., стр. 11]
*  EBITDA Группы составила 118,5 млн евро [.., стр. 11]
*  Амортизация: 22,6 (на 31/12/2025) и 16,5 (на 31/12/2024) [.., стр. 11]
*  Итого чистая денежная позиция/(чистый долг): (112,5) на 31/12/2025
   и 48,8 на 31/12/2024 [.., стр. 11]
```

2) Переход с pypdf на pymupdf4llm — ради таблиц

Проблема: таблицы приходили плоским текстом, числа отрывались от подписей колонок.

Было:
```
104.2 104.1
5 Чистые денежные средства,
полученные от операционной
деятельности, млн евро.
104.8 120.6
6 Расходы на приобретение основных
средств и нематериальных активов
(капитальные затраты), млн евро.
16.6 5.1
```

Стало:
```
|N п/п|Наименование показателя|2023, 12 мес.|2024, 12 мес.|
|---|---|---|---|
|4|Чистая прибыль (убыток), млн евро.|104.2|104.1|
|5|Чистые денежные средства,<br>полученные от операционной<br>деятельности, млн евро.|104.8|120.6|
|6|Расходы на приобретение основных<br>средств и нематериальных активов<br>(капитальные затраты), млн евро.|16.6|5.1|
```

Побочные эффекты разбора в markdown и как решены (модуль `ingest/normalize.py`):

| Эффект | Решение |
|---|---|
| Рамка вокруг маркированного списка становится таблицей из одной колонки | Одноколоночные таблицы разворачиваются обратно в список |
| Обычные абзацы обёрнуты в жирный курсив `**_ _**` | Обрамление снимается |
| Маркеры списка тремя видами: `-`, `•`, `?` | Приводятся к дефису |
| Абзац, перенесённый с предыдущей страницы, помечается заголовком `####` | Заголовок снимается, если первая строка страницы начинается со строчной буквы |

Осталось нерешённым: 18 узлов из 103 содержат часть таблицы без шапки колонок — таблица не помещается
в чанк и режется по лимиту. Лечится увеличением `CHUNK_SIZE` до 2048 либо своим сплиттером,
который не рвёт таблицы.

Из зависимостей ушли `llama-index-readers-file` и `pypdf`.
